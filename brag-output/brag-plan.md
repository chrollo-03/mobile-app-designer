# brag plan: mobile-app-designer

## Answers
- **What is it?** A Claude Code skill that designs a mobile app end to end: iOS and Android
  screens, a clickable prototype, an icon, automated design checks and a build-ready handoff.
- **Who is it for?** People building apps with Claude Code who don't have a designer.
- **What sets it apart?** It drives a real design tool (FigCraft) live over MCP and checks its
  own work: every screen, link, contrast ratio and tap target.
- **Most impressive claim (real):** the Barwise example, 16 screens on iOS and Android,
  137 / 137 design checks passed, 0 contrast or tap-target issues.
- **Visual hook:** a one-line prompt types itself, then 16 phone screens land on the beat.
- **Real UI to show:** the Barwise screens, the real FigCraft screen recording, the prototype
  flow (Today → Workout → Rest), the real `check_design.py` / `audit_design.py` output.
- **Tone:** `default`: punchy, clean, playful only through motion.
- **Share caption:** see `share-copy.txt`.

No personal data appears: the recording shows only the FigCraft window; "Sam" in the app is a
fictional user from the design.

## Music
120 BPM, D major (D, A, Bm, G, one chord per bar), 30 fps: 1 beat = 15 frames, 1 bar = 60
frames. 20 s = 600 frames = 10 bars. Every cut lands on a beat; every sound sits on the same grid.

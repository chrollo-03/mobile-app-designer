# Inspiration: principles borrowed, not looks copied

Look at great work to learn *why* it works, then apply the principle in the product's own style.
Never copy a site's or app's exact layout, illustrations, logo or copy, and never imitate a real
brand closely enough to be mistaken for it.

## From Webflow's marketing site (premium, restrained)

1. **One outcome per section**: a short headline and one supporting line or metric, not a feature
   list. In apps: one purpose per screen, one primary action.
2. **Two-tier calls to action**: one filled primary button + one quiet text link with an arrow
   ("Get started" / "Talk to sales →"). In apps: primary button + text button, never two filled.
3. **Show the product in real context**: real screenshots with real data beat abstract
   illustration. In onboarding and stores, show actual screens doing the main job.
4. **Proof next to claims**: numbers and named sources beside the statement they support
   ("12,480 records stored on this phone").
5. **Repeated, identical block structure** (headline → one line → three bullets → visual → link)
   makes long content scannable. In apps: consistent card anatomy across a list.
6. **Big number as the anchor**: stat blocks lead with a large figure and a small caption, great
   for dashboards, progress and results screens.
7. **Short copy**: headlines of a few words, bullets of one line.

## From designeer.xyz (curation and scanning)

1. **Card = preview + name + one-line "what it is"**, scannable without opening anything.
2. **Filter chips + a secondary sort above a grid**; keep the active chip obvious.
3. **Attribution and source on every item** (avatar, author, favicon) build trust.
4. **Clearly labelled sponsored/promoted slots**, separate from organic content.
5. **A small top nav with one "Submit"/primary action.**

## Where to look for mobile patterns

| Need | Source |
|---|---|
| Real app flows (onboarding, checkout, settings) | Mobbin (mobbin.com), Screenlane, Pttrns |
| Laws and heuristics | Laws of UX (lawsofux.com), Refactoring UI, Practical Typography |
| Platform guidance | Apple Human Interface Guidelines, Material Design 3 (m3.material.io) |
| Visual exploration | Dribbble, Behance (treat as mood, not as shippable UI) |
| Free fonts | Google Fonts, Fontshare, Fontsource, Velvetyne |
| Icons | Lucide, Phosphor, Material Symbols, Tabler, Heroicons, SF Symbols (Apple only) |
| Colour | OKLCH, Huetone, Atmos, Ramps, Color.review, APCA |
| Motion | Rive, Lottie, Motion (motion.dev) |
| Curated everything | designeer.xyz (resources, inspiration, tools) |

When the user names an inspiration site, fetch it (or ask for screenshots), describe the
transferable principles you see, hierarchy, density, type contrast, use of colour, imagery, and
confirm the direction before designing.

# <App name>: <Platform> build kit

Everything needed to build **<App name>** (<one line>) with Claude Code.

## Start here

1. Install the tools in **SETUP.md**.
2. Unzip, open a terminal in this folder, start **Claude Code**.
3. Paste the short prompt at the top of **PROMPT.md**.

## What's inside

| Path | What |
|---|---|
| `PROMPT.md` | Build spec: decisions, screens, behaviour, data, milestones, open questions |
| `SETUP.md` | What to install, device setup, fonts, libraries |
| `design/DESIGN-TOKENS.md` | Colours (light + dark), type, radii, spacing |
| `design/screens/` | Every in-scope screen and sheet as PNG (2×) + `_overview.png` |
| `design/<App>.figcraft` | Source design (zip with `document.json`; clickable in FigCraft) |
| `design/logo/` | Icons, wordmarks, SVGs |
| `reference/` | Rules module + tests, sample (fake) data |

Not included on purpose: <real data, secrets, out-of-scope screens, and why>.
